# Future work

The current release supports libvirt and Helvetios. OpenStack/Chameleon needs a
real provider with media-capability validation and infrastructure acceptance;
there is no success-reporting placeholder.

Future work includes experiment orchestration, dedicated HPL commands, Lmod
integration, cache publishing, Slurm configuration, and classroom workflows.
Classroom work will need per-student resource limits, isolated networks, cleanup
policies, and tested teaching images. These are not current release guarantees.
